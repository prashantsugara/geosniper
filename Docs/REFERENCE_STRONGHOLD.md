# Licensed reference building encounter

Reference: `sample/need_to_build_like_this.mp4`. The video is an advertisement showing scoped shots against roof, terrace and window enemies on a fortified sandstone building. Landscape gameplay remains the game format.

The building uses the licensed Sketchfab Afghan shell and source stairs, extended with an original three-storey open gallery. The former Arab Building wing had solid arch panels and has been removed from the exported mesh. The replacement has genuine arch voids, recessed open doors, timber balcony rails, separate masonry cornices and parapet blocks, external switchback stairs, AC housings with fan grilles, downpipes and utility cables. Licensed desert-house plaster, stone and timber maps provide distinct surfaces; the sandbag source supplies collidable low cover. Source metadata and modification records are in `Store/SketchfabStrongholdLicenses.json` and the in-game Stronghold Credits page.

`ReferenceStronghold` selects a clear, level plot within the sector without occupying mapped roads, buildings, water, parks or the training arena. Its footprint is reserved for later placement checks and displayed through the map feature list. One instance is reused across campaign stages in the loaded sector. If a densely mapped or steep sector has no suitable plot, placement is skipped rather than covering an existing route. Guaranteed placement in every arbitrary GPS sector remains unresolved.

Each successfully prepared standard campaign stage adds the encounter alongside its existing contract. Guards occupy supported source surfaces visible from a reachable existing roof or the current player position. Normal free-roam entry also prepares the encounter. The visible VIEW STRONGHOLD button deploys the player to the supported firing position and faces the building; RETURN TO MISSION restores the saved mission position and view. Campaign briefing and objectives retain their existing route. This corrects the earlier integration, whose captures moved the player manually while normal gameplay only offered a waypoint. Guards use the existing counter-sniper AI, hit volumes, damage, recoil, ammunition, reload and rewards. Their deaths do not replace story targets or increment the main contract kill count. Starting another stage, range mode or duel clears their encounter. Duels retain their existing setup.

The combined building mesh is 16,106 triangles; each sandbag is 712. Two stacked bags per guard are physical cover. Android limits the encounter to two guards (18,978 triangles before the added supply props, including four guard bags and fixtures); desktop uses up to three. Eight 108-triangle licensed NeighborhoodProps timber crates add storage at the ends of the four gallery/roof floor levels, with box collision and a shared source atlas. Two permanent entrance sandbags make ground-level supply cover visible. These props add 2,288 triangles, bringing the Android encounter to about 21,266 triangles and desktop to 22,690, while preserving stair and door clearance. Gallery geometry is batched into five material meshes, alongside five source shell meshes. Shared materials and a bounded cover list avoid accumulating instances across retries. Texture copies are capped at 1024px with mipmaps; original ORM maps are packed into Unity Standard metallic/smoothness and occlusion maps. Stone, plaster and timber remain dielectric. Real-device GPU timing and memory remain required.

Two warm façade fixtures join the existing global nearest-light budget (four lights on Android, eight on desktop), with no shadows. They add warm structure to the arcade at night without increasing that budget. Cloth and plaster are treated as dielectric surfaces; the source cloth's fully white metallic channel is overridden. The stronghold view control is hidden while scoped to keep it clear of the optical HUD.

Reproduce in the isolated Unity review project using `StrongholdCapture.Run`. The capture uses production sector, mission, player, weapon and touch HUD components; enemy AI is held still for repeatable visual and shot measurements. It checks open doors, supported floors/headroom, the actual character controller climbing every exterior stair flight without teleporting, view/return deployment, a scoped shot through production ballistics, ammunition consumption, touch reload input, 50 repeated encounter setups, live counter-sniper acquisition and completion scope reset. `output/reference-building/gameplay` holds the inspected daylight, scoped, hit, entrance and night captures and validation report. It does not certify counter-sniper difficulty, every complete campaign contract or Android performance.

`Tools/build_gallery_android.ps1` copies the complete production source, assets, packages and project settings into `.utmp/android-gallery-build`, then invokes the existing Android development build method there. `-ReuseReviewCache` moves the completed review project's Library cache into this build copy after verifying both paths and checking that review Unity is closed; it saves disk space without touching the main project's cache or open editor. A subsequent isolated gameplay review can regenerate its own Library. Release signing settings and existing APKs/AABs in the main project are preserved.

Use `-ExcludeUnusedAIPackages` for the Android test build. The game's source has no references to the editor AI assistant or inference engine; excluding those packages in the build copy avoids packaging/compiling unused AI compute resources. The main AI package entries are preserved. The screenshot module is now an explicit production dependency because replay and lobby capture scripts use it; the AI tools had previously supplied it transitively. The first complete-package attempt exhausted local disk space during the build; its log/result are retained under `output/reference-building/android-first-*`. Generated caches and duplicate resources in inactive temporary review copies were cleared to recover space; their source and saved renders were retained.

The authored extension has physical floor plates and stair access to every gallery and the roof. `GalleryLayout.json` records floor, door, firing and stair positions in imported model space for collision and traversal validation. The building is turned toward the existing daylight sun without changing the rectangular reserved footprint or adding daytime fill lights. Existing enterable procedural buildings remain available. This building study does not certify the rest of the generated world as reference quality.
