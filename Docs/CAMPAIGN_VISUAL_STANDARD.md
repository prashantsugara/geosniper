# Campaign visual quality standard

All 50 levels target AAA presentation appropriate to a mobile game. This is a production standard, not a claim that the current build is AAA. Recognizable physical props, believable material response, readable silhouettes, grounded interiors, authored animation, contextual interaction, clear navigation, audio feedback and device performance must be reviewed together. Colored boxes are not final mission assets.

Reference: Rebellion Sniper Elite: Resistance (https://store.steampowered.com/app/2169200/Sniper_Elite_Resistance/), particularly environmental staging, varied objectives and infiltration/extraction choices. Use it as a design reference; no extracted game assets.

8 October interior pass: shared plaster/tile/oak surfaces, plaster ceilings, opening trim, furniture details and emissive ceiling fixtures. Evidence/sabotage extraction uses a portable signal case instead of a colored block. See `INTERIOR_ART_PASS.md` for validation and remaining limits.
