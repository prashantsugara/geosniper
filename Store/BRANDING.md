# Geo Sniper branding

Primary logo asset: `Assets/Textures/GameLogo.jpg`. Runtime copy: `Assets/Resources/Branding/GeoSniperLogo.jpg`. Export the Play Store icon with `Geo Sniper > Release > Export Store Icon` after importing the asset in Unity. Apply the Android launcher icon with `Geo Sniper > Release > Apply GameLogo As Android Icon`. The artwork is a square Geo Sniper mark combining the sniper silhouette, globe/GPS signal, and orange/cyan HUD styling.

Android adaptive-mask preview and trademark clearance remain publisher review items. This logo is not a gameplay screenshot. The store icon export only resizes the generated source; no alternative image-generation service was used.

## Generation prompt

Use case: logo-brand. Create the final square app icon and primary emblem for GEO SNIPER, an urban tactical sniper mobile game. Original premium flat graphic identity, charcoal near-black background and warm amber-gold emblem matching a restrained military command-room UI. Single centered bold geometric mark combines a geographic location pin with a precision scope ring and subtle angular G shape, balanced negative space, instantly recognizable at small mobile launcher sizes. Strong thick contours, meticulously clean edges, sophisticated professional game branding. No text, no letters outside the emblem, no character faces, no guns, no blood, no flags, no existing brand logos, no badge border, no watermark, no app-store frame, no rounded canvas corners. Completely opaque square full-bleed charcoal background. Emblem stays comfortably inside the central 62 percent square so Android circular masks will not cut it off. Produce a polished 1024 by 1024 square raster asset.
