# Your footage

Copy your own, rights-cleared vertical MP4 files here. Register them in Growth Studio, preview them, then confirm review before approving posts. Use 1080 x 1920, H.264, 30 fps, AAC 48 kHz / 128 kbps, 3–60 seconds. The built-in renderer creates this format.

Never put other developers' reference videos here. Do not expose a player's home, precise coordinates, account details or private notifications. The system does not read Unity location caches.
